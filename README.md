# Ex-4.-Scenario-Based-Report-Development-Utilizing-Diverse-Prompting-Techniques
Objective: The goal of this experiment is to design and develop an AI-powered chatbot that can handle customer inquiries, provide support, and improve customer experience in a retail environment. Create prompts using various AI prompting techniques to guide your experiment, data collection, analysis, and report creation.
## Aim: 
To develop prompts using diverse AI prompting techniques and use them to create a scenario-based report for a retail customer-support chatbot.
## Algorithm: 
Define the retail chatbot scenario and objectives.
Identify common customer inquiries in a retail environment.
Create prompts using different prompting techniques.
Generate chatbot responses and collect sample outputs.
Analyze the quality, relevance, and usefulness of the responses.
Prepare a structured report summarizing the findings.
Evaluate the effectiveness of each prompting technique.
## Prompt:
Prompting Technique	Prompt
### Zero-Shot Prompting	
You are an AI retail customer support chatbot. Help customers with product inquiries, return/refund requests, order tracking, and troubleshooting. Respond politely and accurately.
### One-Shot Prompting	
Use the given example as a guide and respond to the customer's query about product inquiries, return/refund requests, order tracking, or troubleshooting in the same style.
### Few-Shot Prompting	
Learn from the provided examples and answer customer queries about product inquiries, return/refund requests, order tracking, and troubleshooting in a consistent and helpful manner.
### Role-Based Prompting	
Act as a professional retail customer support executive. Assist customers with product inquiries, return/refund requests, order tracking, and troubleshooting while maintaining a friendly and professional tone.
### Instruction Prompting	
Identify the customer's issue, ask for any missing details if needed, provide a clear and accurate solution, and end the conversation by asking if the customer needs further assistance.

## Result:
The AI-powered chatbot successfully handled product inquiries, return/refund requests, order tracking, and troubleshooting using different prompt engineering techniques. Among them, Instruction Prompting and Role-Based Prompting delivered the most accurate, structured, and customer-friendly responses, resulting in the highest customer satisfaction. Few-Shot Prompting provided detailed and consistent answers, while One-Shot Prompting performed well for common queries. Zero-Shot Prompting was the fastest but was more suitable for simple customer requests. Overall, combining these prompting techniques improved the chatbot's efficiency, response quality, and customer experience.
